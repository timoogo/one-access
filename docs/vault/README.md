# ONE:ACCESS — Vault de conception

Ce vault consolide la session de conception de ONE:ACCESS avant le MVP de démonstration.

## Fichiers

- `01-interview-questions-reponses.md` — les décisions et idées sous forme question/réponse, organisées par thème.
- `02-synthese-par-grands-sujets.md` — vision consolidée par grands sujets, utilisable comme base de spec, pitch ou documentation.

## Statut des idées

Tout ce qui concerne les seuils numériques, pondérations, score d'implication, obligations réglementaires précises et architecture d'industrialisation doit être considéré comme **conceptuel / à expérimenter**, sauf mention contraire.

Le périmètre prioritaire immédiat reste le **MVP de samedi : compréhension + soutien de la vision ONE:ACCESS**.
